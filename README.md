# Esam Sharfeldin - Senior IAM Consultant CV

This is my professional CV built with HTML and Vanilla CSS. It features a premium, high-end consulting design optimized for one-page A4 printing.

## 🚀 Features
- **Confirmed IAM Expert Branding**: Focused on IBM ISIM/ITIM expertise.
- **Premium Design**: Navy-to-Blue gradient header and modern typography.
- **ATS-Friendly**: Clean HTML5 structure.
- **A4 Print Optimized**: Uses CSS `@media print` for professional PDF export.

## 🛠️ Usage
1. Open `index.html` in any modern web browser.
2. Use **`Cmd + P`** (Mac) or **`Ctrl + P`** (Windows) to export as a PDF.
3. Ensure **"Background graphics"** is checked in the print settings.
